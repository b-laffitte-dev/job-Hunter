🐗 Job Hunter AI

Installation grand public — macOS Apple Silicon

Aucune compétence en programmation requise

👉 Ce guide s'adresse à une personne lambda. Vous n'avez besoin d'aucun logiciel préalable (pas de Node.js, pas d'éditeur de code). Le programme est un binaire autonome qui fonctionne directement sur votre Mac (M1, M2, M3 ou M4). Suivez les 4 étapes ci-dessous dans l'ordre.

1 Installer le logiciel

Ouvrez le Terminal : appuyez sur Cmd + Espace, tapez « Terminal » et appuyez sur Entrée.

Copiez-collez ensuite cette ligne (tout en un seul bloc) puis appuyez sur Entrée :

$ curl -fsSL https://raw.githubusercontent.com/b-laffitte-dev/job-Hunter/main/scripts/install-macos.sh | bash

Le script télécharge le programme, l'installe dans ~/.local/bin/ et crée le dossier de configuration ~/.job-hunter-ai/ avec un fichier .env et un config.json. Vos données ne sont pas écrasées si vous réinstallez.

macOS bloque le programme ? Si un message « développeur non vérifié » apparaît, ouvrez Réglages Système → Confidentialité et sécurité et cliquez sur « Autoriser quand même ».

2 Rendre la commande accessible (une seule fois)

Pour pouvoir lancer le logiciel depuis n'importe où, ajoutez son emplacement à votre PATH :

$ echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
$ source ~/.zshrc

Vérifiez que ça fonctionne — cette commande doit afficher l'aide :

$ job-hunter-ai --help
Si vous voyez l'aide s'afficher, cette étape est réussie ✅. Vous ne devrez plus jamais la refaire.

3 Renseigner votre clé IA (gratuite)

L'agent utilise une IA pour générer des mots-clés et classer les offres. La clé est gratuite.

  1. Allez sur console.mistral.ai/api-keys, créez un compte si besoin, puis cliquez sur « Create new key ». Copiez la clé qui s'affiche (elle ne sera plus visible ensuite).
  2. Ouvrez le fichier de configuration dans un éditeur de texte :
$ open -e ~/.job-hunter-ai/.env

3. Remplacez la ligne LLM_API_KEY=your_mistral_api_key par votre vraie clé, par exemple :

LLM_API_KEY=abc123VotreCleCopiee456def

4. Enregistrez le fichier (Cmd+S) puis fermez la fenêtre.

Astuce : pour France Travail (optionnel), vous pouvez aussi renseigner FT_CLIENT_ID et FT_CLIENT_SECRET (à demander sur pole-emploi.io). Sans cela, France Travail est simplement ignoré, les autres sources restent actives.

4 Lancer et discuter avec l'agent

Dans le Terminal :

$ job-hunter-ai --serve

Ouvrez votre navigateur sur http://127.0.0.1:3000 et discutez avec l'agent, par exemple :

  • cherche secrétariat médico social à Lyon
  • seulement en CDI
  • lance la recherche

Pour arrêter : appuyez sur Ctrl+C dans le Terminal.

Les résultats sont sauvegardés dans ~/.job-hunter-ai/data/. Pour les consulter dans le Finder :

$ open ~/.job-hunter-ai

⚡ En résumé — 4 commandes

$ curl -fsSL https://raw.githubusercontent.com/b-laffitte-dev/job-Hunter/main/scripts/install-macos.sh | bash
$ echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
$ open -e ~/.job-hunter-ai/.env   # collez votre clé Mistral, puis Cmd+S
$ job-hunter-ai --serve

Puis ouvrez http://127.0.0.1:3000.

🍎 Mac Intel (x64)

Le binaire distribué est conçu pour Apple Silicon. Pour savoir quelle puce vous avez : menu → À propos de ce Mac → ligne « Puce ».

Si « Intel » apparaît, installez d'abord Node.js 22+, puis :

$ git clone https://github.com/b-laffitte-dev/job-Hunter.git
$ cd job-Hunter && npm install && npm run serve
